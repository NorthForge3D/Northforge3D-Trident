# Frame — NF3D Trident

The parts in this directory are **optional frame stiffeners** designed specifically for the **first dual-gantry NF3D Trident**.

These parts are included for two reasons:

1. **Frame Stiffening**  
   When installed, these parts increase overall frame rigidity.  
   Use of these parts requires **additional M5 fasteners and T-nuts** beyond the standard Trident bill of materials.

2. **Frame Squaring Aid (Use With Caution)**  
   If printed on a **well-tuned printer** and **confirmed to be exactly square using a machinist square**, these parts can assist in building and squaring the entire frame during assembly.

   ⚠️ **Warning:**  
   If printer accuracy and part squareness are **not verified with a machinist square**, these parts may **lock errors into the frame** rather than correct them. In this case, they can work *against* you instead of helping.

These parts diverge from the stock Voron Trident design and are intended for use only with the NF3D Trident geometry and documentation.
