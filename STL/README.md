# STL Files — NF3D Trident

This directory contains STL files for the **NF3D Trident** build.

All STL files housed here have been **validated through real-world use** and have been printed and confirmed on an operating printer. These files may be downloaded, printed, and used to build your own NF3D Trident.

Most STL files in this directory **diverge from the stock Voron Trident design**. They are **not interchangeable** with standard Voron Trident parts unless explicitly stated. Substituting these parts into a stock Trident build, or vice versa, may result in fitment or functional issues.

Only tested, confirmed parts are included here. Experimental or in-progress designs are intentionally excluded.
