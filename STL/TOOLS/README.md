# Tools — NF3D Trident

This directory contains **tools and jigs** used to build the **NF3D Trident**.

Files in this directory are **not printer parts**. They are intended to assist with fabrication, alignment, and modification tasks during the build process (e.g. drilling jigs, alignment guides, and setup tools).

Some tools in this directory may be **generally useful** for other builds or projects. Others are **specific to the NF3D Trident** and are designed to be used in conjunction with this printer’s geometry and documentation.

All tools housed here have been **used and validated** during the NF3D Trident build process. Improper use may result in permanent damage to parts or materials—review the associated documentation before use.
